# Facturas Radio Nueva Moda

Web para rellenar, numerar y descargar facturas en PDF.

Dirección pública (GitHub Pages):

https://larrosayasociados-alt.github.io/facturas-radio-nueva-moda/

## Cómo usarla

1. Complete el cliente y los importes.
2. Pulse **Descargar PDF**.
3. Envíe al cliente por **WhatsApp** o **Email**. El mensaje se abre listo; adjunte el PDF descargado.

La numeración es correlativa y no reutiliza números. Los datos se guardan en el navegador. Use **Exportar copia** si va a cambiar de ordenador.
